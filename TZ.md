# Техническое Задание (ТЗ): Система электронной очереди "Spanda" для KICB

## 1. Общее описание
Система предназначена для управления потоками клиентов в отделениях банка KICB. Основная цель — автоматизация процесса ожидания, повышение качества обслуживания и сбор статистики.

## 2. Ключевые требования
- **Отказоустойчивость:** Работа филиала не должна зависеть от наличия интернет-соединения с центральным сервером.
- **Скорость:** Мгновенное обновление данных на табло и в окнах сотрудников (использование WebSockets).
- **Масштабируемость:** Поддержка более 50 филиалов с количеством сотрудников от 2 до 40 в каждом.
- **Контейнеризация:** Полная работа через Docker.

## 3. Архитектура системы
Система состоит из двух типов серверов:
1.  **Центральный сервер (Central Server):**
    - Управление списком услуг, приоритетами и сотрудниками.
    - Глобальный мониторинг всех филиалов в реальном времени.
    - Сбор и хранение агрегированной статистики.
2.  **Сервер филиала (Branch Server):**
    - Локальное управление очередью.
    - Автономная работа при обрыве связи.
    - Автоматическая синхронизация с центром (раз в 1-2 минуты или по запросу).

## 4. Пользовательские интерфейсы
1.  **Терминал (Terminal):**
    - Двухуровневое меню выбора услуг.
    - Выдача талона (визуально и на печать ESC/POS).
    - Выбор языка (Русский, Кыргызский, Английский).
2.  **Окно Сотрудника (Operator):**
    - Авторизация сотрудника.
    - Вызов следующего клиента (с учетом приоритетов услуг).
    - Настройка видимости услуг (только свои или все).
3.  **Информационное Табло (TV Display):**
    - Отображение номера вызываемого талона и номера окна.
    - Звуковое оповещение (опционально).
    - Список последних 5-10 вызовов.
4.  **Мониторинг/Админка:**
    - Просмотр статуса филиалов (Online/Offline).
    - Детальная статистика по очередям, времени ожидания и работе сотрудников.

## 5. Технологический стек
- **Backend:** Python (FastAPI).
- **Database:** PostgreSQL (основное хранилище), Redis (состояние очереди в реальном времени).
- **Frontend:** React + Tailwind CSS.
- **Real-time:** WebSockets.
- **Deployment:** Docker & Docker Compose.

## 6. Безопасность и Доступ
- Ролевая модель доступа: Admin, Operator, Terminal, TV.
- Стандартные учетные данные для первичного входа: `admin` / `Password123`.
- Шифрование паролей: BCrypt.

## 7. Брендинг
- Основные цвета: Синий (#0A3A6B) и Зеленый (#00A859).
- Стиль: Корпоративный стандарт KICB Bank.
