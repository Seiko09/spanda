# Инструкция по запуску системы электронной очереди KICB Spanda

## 1. Запуск проекта
Выполните команду в терминале:
```bash
docker-compose up --build
```

## 2. Доступ к системе
После запуска вы можете войти в систему по любой из этих ссылок:
- **http://localhost:3000** (Основной вход)
- **http://localhost:8000** (Центральный сервер)
- **http://localhost:8001** (Сервер филиала)

## 3. Окна системы
На главной странице выберите нужный режим:
1. **Terminal** — Окно для клиентов (выдача талонов).
2. **Operator** — Окно сотрудника банка.
3. **TV Display** — Информационное табло.
4. **Admin** — Мониторинг и отчеты.

## 4. Вход для администратора
- **Логин:** `admin`
- **Пароль:** `Password123`

## 5. Особенности
- **Отказоустойчивость:** Если центральный сервер (8000) недоступен, филиал (8001) продолжает работать полностью автономно.
- **Скорость:** Используется Redis для моментального обновления очереди.
- **Стиль:** Интерфейс выполнен в фирменных цветах KICB (Синий и Зеленый).
