# Инструкция по запуску системы электронной очереди KICB Spanda (Unified Edition)

Теперь система полностью объединена. Каждый сервер (Центральный или Филиал) содержит в себе и логику (Backend), и интерфейс (Frontend).

## 1. Запуск проекта
Просто выполните команду:

```bash
docker-compose up --build
```

## 2. Доступ к интерфейсам
После запуска система доступна по двум адресам:

*   **Центральный сервер:** **http://localhost:8000**
    (Используйте для управления всеми филиалами и глобальной настройки)
*   **Локальный сервер филиала:** **http://localhost:8001**
    (Используйте для работы терминала, оператора и табло в конкретном филиале)

## 3. Режимы работы (внутри одного адреса)
Открыв любой из адресов, вы попадете в общее меню выбора:
1.  **Terminal:** Окно для выдачи талонов.
2.  **Operator:** Окно для сотрудников банка.
3.  **TV Display:** Табло для зала ожидания.
4.  **Admin:** Глобальный мониторинг и отчеты.

## 4. Данные для входа
- **Логин:** `admin`
- **Пароль:** `Password123`

## 5. Что изменилось?
- **Единый Docker-образ:** Мы используем один файл `Dockerfile` для сборки всего приложения.
- **Упрощенная архитектура:** Больше не нужно отдельно запускать frontend на 3000 порту. Все работает через 8000 (Центр) или 8001 (Филиал).
- **Отказоустойчивость:** Филиал на порту 8001 полностью автономен. Если центральный сервер (8000) упадет, филиал продолжит выдавать талоны и обслуживать клиентов.
