# Инструкция по запуску системы электронной очереди KICB Spanda

Система представляет собой распределенное решение с центральным сервером управления и локальными серверами филиалов для обеспечения отказоустойчивости.

## 1. Требования
- Docker
- Docker Compose

## 2. Запуск проекта
Для запуска всей системы (Центр + Филиал + Frontend) выполните команду в корневой директории:

```bash
docker-compose up --build
```

## 3. Доступ к интерфейсам
После запуска Frontend будет доступен по адресу: **http://localhost:3000**

На главной странице вы можете выбрать нужный режим работы:

1.  **Окно Терминала (Terminal):** Для выбора услуг и получения талона клиентом.
2.  **Окно Сотрудника (Operator):** Для вызова клиентов, управления очередью в окне.
3.  **Информационное Табло (TV Display):** Для отображения текущих вызовов в зале ожидания.
4.  **Окно Администратора (Admin):** Для мониторинга состояния филиалов и настройки системы.

## 4. Данные для входа (Администратор)
- **Логин:** `admin`
- **Пароль:** `Password123`

## 5. Архитектура и Отказоустойчивость
- **Central Server (Порт 8000):** Глобальное управление услугами, сотрудниками и сбор статистики со всех филиалов.
- **Branch Server (Порт 8001):** Локальный сервер филиала. Работает автономно. Если связь с центром пропадет, очередь в филиале продолжит функционировать.
- **Базы данных:** PostgreSQL используется для надежного хранения, Redis — для мгновенного обновления статусов очереди.

## 6. Печать талонов
Система подготовлена к интеграции с принтерами по протоколу ESC/POS. При генерации талона в окне терминала выводится форма, оптимизированная для чековой печати.

## 7. Локализация
В верхнем правом углу любого окна можно переключить язык системы:
- Русский (RU)
- Кыргызча (KY)
- English (EN)
